# Contributing to SORA Frame

Thanks for helping improve SORA Frame. Useful contributions include bug fixes, accessibility improvements, documentation corrections, tests, and small feature enhancements.

## Before you start

1. Check [open issues](../../issues) and [Discussions](../../discussions) for existing work and questions.
2. For a significant change, open a Discussion or issue first so the approach can be agreed.
3. Do not include passwords, API keys, or real photos in a pull request.

## Submitting a pull request

1. Fork the repository and create a focused branch.
2. Make and test your change locally. Server tests run with `npm test -- --runInBand` from the `server` directory.
3. Describe what changed and how you tested it in the pull request.

## Pair contributions

When two people work on a commit, the commit author can credit the collaborator by adding a trailer such as:

```text
Co-authored-by: Collaborator Name <collaborator@users.noreply.github.com>
```

Only add this when the collaborator made a real contribution to that commit.
